# 快速启动指南 - DeepSeek + 本地Embedding版本

## 🚀 5分钟快速启动

### 前置条件
- Python 3.8+
- 已配置 `DEEPSEEK_API_KEY`

### 启动步骤

```bash
# 1. 安装依赖（首次运行）
pip install sentence-transformers -i https://pypi.tuna.tsinghua.edu.cn/simple

# 2. 清理旧embedding（如果之前用过OpenAI）
rm ITINERA/model/data/*.npy

# 3. 启动服务
cd ITINERA
python server.py
```

### 首次启动会自动：
1. ✓ 下载本地Embedding模型（约400MB，仅首次）
2. ✓ 生成数据集的embedding文件（约30秒）
3. ✓ 启动Web服务（http://localhost:8000）

## ⚠️ 常见问题

### 问题1：模型下载慢
```bash
# 设置国内镜像
export HF_ENDPOINT=https://hf-mirror.com
python server.py
```

### 问题2：内存不足
修改 `config/app_config.json`：
```json
{
  "LOCAL_EMBEDDING_MODEL": "shibing624/text2vec-base-chinese"
}
```

### 问题3：DeepSeek API错误
检查API Key是否有效：
```bash
curl https://api.deepseek.com/v1/chat/completions \
  -H "Authorization: Bearer sk-c58fbe40a7ff4d24bcc8d15f07883f0b" \
  -H "Content-Type: application/json" \
  -d '{"model":"deepseek-chat","messages":[{"role":"user","content":"测试"}]}'
```
