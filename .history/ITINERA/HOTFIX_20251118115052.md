# 热修复：移除已删除参数的调用

## 问题

清理冗余代码后，`server.py` 中仍在传递已删除的参数，导致运行时错误：

```
TypeError: SiteSelector.__init__() got an unexpected keyword argument 'blend_w_safe'
```

## 修复内容

### 修改文件：`server.py`

#### 1. 移除参数传递
```python
# 修复前
selector = SiteSelector(
    user_reqs=requirements,
    city=city,
    min_site_candidate_num=min_site_candidate_num,
    proxy_call=proxy,
    type=type_,
    blend_w_text=w_text,
    blend_w_safe=w_safe,      # ❌ 已删除
    enable_safe=False,         # ❌ 已删除
    dataset_path=dataset_csv_path
)

# 修复后
selector = SiteSelector(
    user_reqs=requirements,
    city=city,
    min_site_candidate_num=min_site_candidate_num,
    proxy_call=proxy,
    type=type_,
    blend_w_text=w_text,
    dataset_path=dataset_csv_path
)
```

#### 2. 移除变量定义
```python
# 修复前
w_text = 1.0
w_safe = 0.0  # ❌ 已删除

# 修复后
w_text = 1.0
```
