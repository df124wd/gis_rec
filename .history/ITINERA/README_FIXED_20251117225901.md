## ⚠️ 常见问题

### Q1: 模型下载慢？
```bash
# 设置国内镜像
export HF_ENDPOINT=https://hf-mirror.com
python server.py
```

### Q2: 内存不足？
修改 `config/app_config.json`：
```json
{
  "LOCAL_EMBEDDING_MODEL": "shibing624/text2vec-base-chinese"
}
```

### Q3: DeepSeek余额不足？
- 充值地址：https://platform.deepseek.com/
- 建议充值：¥10-50（够用很久）
- 或临时切换回OpenAI（修改配置文件）

### Q4: 仍然报错 "Model Not Exist"？
检查以下内容：
1. 确认 `config/app_config.json` 中**没有** `OPENAI_CHAT_MODEL` 配置项
2. 确认 `DEEPSEEK_API_KEY` 有效
3. 重启服务
