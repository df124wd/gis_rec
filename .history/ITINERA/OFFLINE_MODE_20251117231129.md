# 离线模式说明

## 问题现象

模型已下载成功，但运行时仍然尝试访问 `huggingface.co`：
```
Connection to huggingface.co timed out
Retrying in 1s [Retry 1/5]
```

## 原因

`sentence-transformers` 库在加载模型时会尝试检查远程是否有更新版本，即使本地已有缓存。

## 解决方案

### ✅ 已自动修复

代码已自动设置离线模式：
```python
os.environ['TRANSFORMERS_OFFLINE'] = '1'
os.environ['HF_HUB_OFFLINE'] = '1'
```

现在重新运行即可：
```powershell
python D:\gis_rec\ITINERA\scripts\test_config.py
```

应该看到：
```
[Embedding] 加载本地模型: BAAI/bge-base-zh-v1.5 (离线模式)
✓ Embedding生成成功
```

## 工作原理

### 下载阶段（需要联网）
```python
# download_model.py
os.environ['TRANSFORMERS_OFFLINE'] = '0'  # 在线模式
os.environ['HF_ENDPOINT'] = 'https://hf-mirror.com'  # 使用镜像
```

### 使用阶段（无需联网）
```python
# proxy_call.py
os.environ['TRANSFORMERS_OFFLINE'] = '1'  # 离线模式
# 直接从本地缓存加载，不访问网络
```

## 手动设置离线模式

如果自动设置失败，可以手动设置环境变量：

**PowerShell**:
```powershell
$env:TRANSFORMERS_OFFLINE = "1"
$env:HF_HUB_OFFLINE = "1"
python server.py
```

**CMD**:
```cmd
set TRANSFORMERS_OFFLINE=1
set HF_HUB_OFFLINE=1
python server.py
```

**Linux/Mac**:
```bash
export TRANSFORMERS_OFFLINE=1
export HF_HUB_OFFLINE=1
python server.py
```

## 使用本地路径（终极方案）

如果离线模式还是有问题，可以直接指定本地路径：

1. 查找模型路径：
```powershell
python scripts/find_model.py
```

2. 复制输出的路径，例如：
```
C:\Users\你的用户名\.cache\huggingface\hub\models--BAAI--bge-base-zh-v1.5\snapshots\abc123def
```

3. 修改 `config/app_config.json`：
```json
{
  "LOCAL_EMBEDDING_MODEL": "C:/Users/你的用户名/.cache/huggingface/hub/models--BAAI--bge-base-zh-v1.5/snapshots/abc123def"
}
```

注意：Windows路径使用正斜杠 `/` 或双反斜杠 `\\`

## 常见问题

### Q1: 为什么第一次下载成功，第二次还要联网？
- `sentence-transformers` 默认会检查更新
- 已通过设置 `TRANSFORMERS_OFFLINE=1` 禁用

### Q2: 离线模式会影响功能吗？
- 不会，模型已完整下载到本地
- 离线模式只是跳过更新检查

### Q3: 如何确认真的在离线运行？
- 断开网络连接
- 运行 `python scripts/test_config.py`
- 如果成功，说明确实离线

### Q4: 模型会自动更新吗？
- 离线模式下不会
- 如果需要更新，删除缓存重新下载：
  ```powershell
  Remove-Item -Recurse -Force $env:USERPROFILE\.cache\huggingface
  python scripts/download_model.py
  ```
