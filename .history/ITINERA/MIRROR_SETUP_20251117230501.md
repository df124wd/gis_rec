# HuggingFace镜像配置指南

## 问题现象

下载模型时出现超时错误：
```
Connection to huggingface.co timed out
```

## 解决方案

### 方案1：临时设置环境变量（推荐）

**PowerShell**:
```powershell
$env:HF_ENDPOINT = "https://hf-mirror.com"
python server.py
```

**CMD**:
```cmd
set HF_ENDPOINT=https://hf-mirror.com
python server.py
```

**Linux/Mac**:
```bash
export HF_ENDPOINT=https://hf-mirror.com
python server.py
```

### 方案4：使用更小的模型

如果网络实在太慢，可以使用更小的模型：

编辑 `config/app_config.json`：
```json
{
  "LOCAL_EMBEDDING_MODEL": "shibing624/text2vec-base-chinese"
}
```

这个模型：
- 大小：约200MB（比bge-base小一半）
- 速度：更快
- 效果：略差但够用

## 常见问题

### Q1: 镜像还是慢？
- 检查网络连接
- 尝试使用VPN
- 或使用更小的模型（见方案4）

### Q2: 下载到一半中断了？
- 重新运行，会自动续传
- 或删除缓存重新下载：
  ```powershell
  Remove-Item -Recurse -Force $env:USERPROFILE\.cache\huggingface
  ```

### Q3: 模型下载到哪里了？
- Windows: `C:\Users\你的用户名\.cache\huggingface\hub\`
- Linux/Mac: `~/.cache/huggingface/hub/`

### Q4: 如何手动下载模型？
使用git-lfs：
```bash
# 安装git-lfs
git lfs install

# 从镜像下载
git clone https://hf-mirror.com/BAAI/bge-base-zh-v1.5

# 配置使用本地路径
{
  "LOCAL_EMBEDDING_MODEL": "D:/models/bge-base-zh-v1.5"
}
```
