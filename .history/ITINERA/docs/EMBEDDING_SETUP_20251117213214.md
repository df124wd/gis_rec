# Embedding模型配置指南

## 为什么要切换到本地Embedding？

1. **成本节省**：OpenAI Embedding API按Token收费，大量数据会产生高额费用
2. **速度更快**：本地模型无网络延迟，批量处理速度更快
3. **数据安全**：数据不离开本地服务器
4. **中文优化**：国内开源模型针对中文场景优化，效果更好

## 快速开始

### 1. 安装依赖

```bash
# 安装sentence-transformers（包含PyTorch）
pip install sentence-transformers

# 如果网络慢，使用清华镜像
pip install sentence-transformers -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 2. 配置文件

编辑 `config/app_config.json`：

```json
{
  "EMBEDDING_PROVIDER": "local",
  "LOCAL_EMBEDDING_MODEL": "BAAI/bge-base-zh-v1.5"
}
```

### 3. 首次运行（自动下载模型）

```bash
python server.py
```

模型会自动下载到 `~/.cache/huggingface/hub/`

**国内加速下载**：
```bash
# 设置镜像源
export HF_ENDPOINT=https://hf-mirror.com

# 或手动下载
git lfs install
git clone https://hf-mirror.com/BAAI/bge-base-zh-v1.5
```

### 4. 重新生成Embedding

由于模型维度可能不同，需要重新生成数据集的embedding：

```bash
# 删除旧的embedding文件
rm ITINERA/model/data/*.npy

# 重启服务，会自动重新生成
python server.py
```

```python
self._local_model = SentenceTransformer(model_name, device='cuda')
```

### 自定义模型路径

```json
{
  "LOCAL_EMBEDDING_MODEL": "/path/to/your/model"
```

## 常见问题

### Q1: 模型下载失败？
```bash
# 使用镜像源
export HF_ENDPOINT=https://hf-mirror.com
pip install -U huggingface_hub
```

### Q2: 内存不足？
使用更小的模型：
```json
{
  "LOCAL_EMBEDDING_MODEL": "shibing624/text2vec-base-chinese"
}
```

### Q3: 维度不匹配错误？
删除旧的.npy文件重新生成：
```bash
rm ITINERA/model/data/*.npy
```

### Q4: 效果不如OpenAI？
- bge-large-zh-v1.5 在中文场景下效果接近甚至超过OpenAI
- 可以通过微调进一步提升效果
