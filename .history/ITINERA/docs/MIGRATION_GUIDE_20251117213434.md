# 迁移指南：切换到DeepSeek + 本地Embedding

## 快速开始（5分钟完成）

### 方式1：自动迁移脚本（推荐）

```bash
# 进入项目目录
cd ITINERA

# 运行迁移脚本
python scripts/migrate_to_deepseek.py
```

脚本会自动完成：
1. ✓ 备份原配置
2. ✓ 更新配置文件
3. ✓ 清理旧embedding
4. ✓ 安装依赖
5. ✓ 下载模型

### 方式2：手动迁移

#### Step 1: 安装依赖
```bash
pip install sentence-transformers -i https://pypi.tuna.tsinghua.edu.cn/simple
```

#### Step 2: 修改配置
编辑 `config/app_config.json`：

```json
{
  "DEEPSEEK_API_KEY": "sk-c58fbe40a7ff4d24bcc8d15f07883f0b",
  "OPENAI_API_KEY": "",
  "EMBEDDING_PROVIDER": "local",
  "LOCAL_EMBEDDING_MODEL": "BAAI/bge-base-zh-v1.5"
}
```

#### Step 3: 清理旧embedding
```bash
rm model/data/*.npy
```

#### Step 4: 启动服务
```bash
python server.py
```

首次启动会自动：
- 下载本地Embedding模型（约400MB）
- 重新生成数据集的embedding文件

## 配置选项详解

### 1. LLM提供商选择

#### 使用DeepSeek（推荐，成本低）
```json
{
  "DEEPSEEK_API_KEY": "sk-xxx",
  "OPENAI_API_KEY": ""
}
```

#### 使用OpenAI（备用）
```json
{
  "DEEPSEEK_API_KEY": "",
  "OPENAI_API_KEY": "sk-xxx",
  "OPENAI_BASE_URL": "https://api.openai.com/v1"
}
```

#### 混合使用
```json
{
  "DEEPSEEK_API_KEY": "sk-xxx",
  "OPENAI_API_KEY": "sk-yyy"
}
```
系统会优先使用DeepSeek，OpenAI作为备用。

---

### 2. Embedding提供商选择

#### 本地模型（推荐，免费）
```json
{
  "EMBEDDING_PROVIDER": "local",
  "LOCAL_EMBEDDING_MODEL": "BAAI/bge-base-zh-v1.5"
}
```

**可选模型**：
- `BAAI/bge-large-zh-v1.5` - 最佳效果，需GPU
- `BAAI/bge-base-zh-v1.5` - 平衡选择（推荐）
- `shibing624/text2vec-base-chinese` - 轻量快速
- `moka-ai/m3e-base` - 多语言支持

#### OpenAI Embedding（付费）
```json
{
  "EMBEDDING_PROVIDER": "openai",
  "OPENAI_API_KEY": "sk-xxx",
  "OPENAI_EMBEDDING_MODEL": "text-embedding-ada-002"
}
```

## 常见问题

### Q1: 模型下载慢或失败？

**方案A：使用国内镜像**
```bash
export HF_ENDPOINT=https://hf-mirror.com
python server.py
```

**方案B：手动下载**
```bash
# 安装git-lfs
git lfs install

# 从镜像下载
git clone https://hf-mirror.com/BAAI/bge-base-zh-v1.5

# 配置使用本地路径
{
  "LOCAL_EMBEDDING_MODEL": "/path/to/bge-base-zh-v1.5"
}
```

**方案C：使用更小的模型**
```json
{
  "LOCAL_EMBEDDING_MODEL": "shibing624/text2vec-base-chinese"
}
```

---

### Q2: 维度不匹配错误？

```
ValueError: shapes (1536,) and (768,) not aligned
```

**原因**：旧的embedding是OpenAI生成的（1536维），新模型是768维

**解决**：
```bash
# 删除旧embedding
rm model/data/*.npy

# 重启服务，自动重新生成
python server.py
```

---

### Q3: 内存不足？

**错误信息**：
```
RuntimeError: CUDA out of memory
```

**解决方案**：

1. 使用CPU（自动降级）
2. 使用更小的模型：
```json
{
  "LOCAL_EMBEDDING_MODEL": "shibing624/text2vec-base-chinese"
}
```
3. 减少批处理大小（修改`proxy_call.py`）

---

### Q4: DeepSeek API限流？

**错误信息**：
```
Rate limit exceeded
```

**解决方案**：

1. 添加重试逻辑（已内置）
2. 降低并发请求
3. 升级DeepSeek套餐
4. 临时切换回OpenAI：
```json
{
  "OPENAI_API_KEY": "sk-xxx"
}
```

---

### Q5: 效果不如OpenAI？

**对比测试**：

```python
# 测试脚本
from model.utils.proxy_call import OpenaiCall

# 测试查询
query = "天河区工业用地，靠近地铁"

# OpenAI
proxy_openai = OpenaiCall(provider="openai")
result_openai = proxy_openai.embedding(query)

# 本地模型
proxy_local = OpenaiCall(provider="deepseek")
result_local = proxy_local.embedding(query)

# 对比相似度
```

**优化建议**：

1. 使用更大的模型：`bge-large-zh-v1.5`
2. 微调模型（针对你的数据集）
3. 调整检索参数（top_k、阈值等）

## 性能优化

### 1. 使用GPU加速

修改 `model/utils/proxy_call.py`：

```python
def _local_embedding(self, input_data):
    if not hasattr(self, '_local_model'):
        self._local_model = SentenceTransformer(
            model_name,
            device='cuda'  # 使用GPU
        )
```

**效果**：速度提升5-10倍

---

### 2. 批量处理优化

```python
# 增加批处理大小
embeddings = self._local_model.encode(
    texts,
    batch_size=128,  # 默认32，可增加到128
    normalize_embeddings=True
)
```

---

### 3. 模型量化（减少内存）

```python
from sentence_transformers import SentenceTransformer
import torch

model = SentenceTransformer(model_name)
model.half()  # FP16量化，内存减半
```
