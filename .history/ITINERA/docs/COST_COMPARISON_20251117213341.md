## 场景1：单次推荐请求

### 假设
- 用户需求：50 tokens
- 候选地块：10个，每个100 tokens
- LLM生成报告：500 tokens

### OpenAI方案
```
需求解析: 50 tokens × $0.0015 = $0.000075
Embedding查询: 50 tokens × $0.0001 = $0.000005
候选Embedding: 1000 tokens × $0.0001 = $0.0001
报告生成: (1050输入 + 500输出) × $0.0015/$0.002 = $0.002575

总计: $0.002655 ≈ ¥0.019 (按1:7汇率)
```

### DeepSeek + 本地Embedding方案
```
需求解析: 50 tokens × ¥0.001 = ¥0.00005
Embedding查询: 免费
候选Embedding: 免费
报告生成: (1050输入 + 500输出) × ¥0.001/¥0.002 = ¥0.00205

总计: ¥0.0021 ≈ $0.0003
```

**单次节省**: 93% ($0.002655 → $0.0003)
